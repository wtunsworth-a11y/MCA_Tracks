# points carry a note the recorder typed - "Non-operational. Now covered in

# that is the part no coordinate replaces. Read the note column before
# assuming a facility on this list is a facility in use.
#
# Names are exactly as recorded in the field, with the capture timestamp split
# out of the name into its own column. Nothing has been renamed or reconciled
# against our own places here; that happens downstream where it can be
# reviewed.
